#Real-Time Chat App 

a real-time group chat app built wiht React, Node.js, Express, socket.IO and MongoDB.

##Features 
. Join with username
. Real-time messaging with Socket.IO
. Chat history saved in MongoDB
. Typing indicator
. Auto-scroll to lates message

##Tech Stack
. Fronted: React(Vite)
. Backend : Node.js, Express, Socket.IO
. Database: MongoDB Atls (Mongoose)

##Setup 
###1.Backed 
cd server
npm install
Copy .env.example to .env and add your MongoDB connecction string
npm run dev
Server run s on http://localhost:5000

###2.fronted cd client npm install
npm run dev
App run son http:///localhost:5173

##Testin 
Open the app in two browser tabs, join with different names and chat. Messages, typin an donline status update live
